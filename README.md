# About My Favorite Movie, Avengers

![Avengers](https://static.wikia.nocookie.net/marvelcinematicuniverse/images/d/de/Avengers_Endgame_International.jpg/revision/latest?cb=20190323034207)

**The Avengers** are a fictional team of superheroes—headlined as "Earth's Mightiest Heroes"—created by writer-editor Stan Lee and artist/co-plotter Jack Kirby. They serve as the planet's first line of defense against massive terrestrial and extraterrestrial threats that no single hero could withstand alone.
